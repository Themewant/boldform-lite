Bold Form Lite — Developer Guide

Extend, customize, and integrate with Bold Form using hooks, filters, and the plugin's architecture.

Bold Form Lite is designed with extensibility in mind. Every major operation — rendering, saving, validation, email — passes through WordPress filters and actions. This guide covers the public API surface available to developers.

Architecture

Plugin Bootstrap

The plugin initializes on plugins_loaded via a singleton pattern:

// boldform-lite.php
function boldform_lite() {
    return BoldForm_Lite::get_instance();
}
add_action( 'plugins_loaded', 'boldform_lite' );

Database Schema

wp_boldform_forms

CREATE TABLE wp_boldform_forms (
  id            BIGINT(20) UNSIGNED NOT NULL AUTO_INCREMENT,
  title         VARCHAR(191) NOT NULL,
  status        VARCHAR(20)  NOT NULL DEFAULT 'draft',   -- draft | publish | trash
  fields_json   LONGTEXT     NOT NULL,                   -- JSON: { rows: [...] }
  settings_json LONGTEXT     NULL,                       -- JSON: form settings
  created_by    BIGINT(20) UNSIGNED NOT NULL DEFAULT 0,
  created_at    DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at    DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY status (status),
  KEY created_by (created_by)
);

wp_boldform_entries

CREATE TABLE wp_boldform_entries (
  id              BIGINT(20) UNSIGNED NOT NULL AUTO_INCREMENT,
  form_id         BIGINT(20) UNSIGNED NOT NULL,
  entry_data_json LONGTEXT     NOT NULL,                 -- JSON: { field_id: value, ... }
  submission_key  VARCHAR(64)  NULL,                     -- unique submission identifier
  user_id         BIGINT(20) UNSIGNED NOT NULL DEFAULT 0,
  user_ip         VARCHAR(100) NULL,
  user_agent      TEXT         NULL,
  status          VARCHAR(20)  NOT NULL DEFAULT 'unread', -- unread | read | starred
  created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY form_id (form_id),
  KEY status (status),
  KEY created_at (created_at),
  KEY submission_key (submission_key)
);
Multisite: On multisite, each sub-site gets its own tables (e.g. wp_2_boldform_forms). Tables are created on network activation, new site creation, and via a plugins_loaded safety net.

Form Rendering Hooks

boldform_form_output

Filter the complete rendered form HTML before output.

add_filter( 'boldform_form_output', function( $html, $form_id, $form_record, $settings ) {
    // Wrap form in a custom container
    return '<div class="my-form-wrapper">' . $html . '</div>';
}, 10, 4 );

boldform_field_control_html

Filter the inner HTML of any field control. This is the primary hook for adding custom field type rendering.

add_filter( 'boldform_field_control_html', function( $html, $type, $field_name, $field ) {
    if ( 'my_custom_type' === $type ) {
        return '<div class="my-field">Custom field HTML</div>';
    }
    return $html;
}, 10, 4 );
ParameterTypeDescription
$htmlstringCurrent control HTML from Lite's renderer
$typestringField type slug
$field_namestringInput name attribute (e.g. boldform_field_abc)
$fieldarrayFull field definition array

boldform_field_conditional_attrs

Modify the conditional logic data attributes on field wrappers.

add_filter( 'boldform_field_conditional_attrs', function( $attrs, $field ) {
    // Add custom data attributes
    return $attrs;
}, 10, 2 );

boldform_max_file_size

Override the maximum file upload size (in MB) per field.

add_filter( 'boldform_max_file_size', function( $max_mb, $field ) {
    if ( 'resume' === ( $field['css_class'] ?? '' ) ) {
        return 10; // Allow 10 MB for resume uploads
    }
    return $max_mb;
}, 10, 2 );

Custom Field Types

boldform_field_library

Add new field types to the builder's sidebar library.

add_filter( 'boldform_field_library', function( $library ) {
    $library['color_picker'] = array(
        'label' => 'Color Picker',
        'icon'  => 'dashicons-art',
        'group' => 'advanced',
    );
    return $library;
} );

boldform_builder_field_groups

Add new field group headings in the sidebar.

add_filter( 'boldform_builder_field_groups', function( $groups ) {
    $groups['custom'] = 'My Custom Fields';
    return $groups;
} );

boldform_allowed_field_types

Whitelist your custom field type so it passes save validation.

add_filter( 'boldform_allowed_field_types', function( $types ) {
    $types[] = 'color_picker';
    return $types;
} );

boldform_field_extra_keys

Persist additional field properties during form save.

add_filter( 'boldform_field_extra_keys', function( $extra, $field, $field_type ) {
    if ( 'color_picker' === $field_type ) {
        $extra['default_color'] = sanitize_hex_color( $field['default_color'] ?? '#000000' );
    }
    return $extra;
}, 10, 3 );

Submission Flow Hooks

The submission lifecycle in order:

  1. boldform_gate_submission — accept or reject before validation
  2. boldform_before_submission — fires before field validation
  3. boldform_submission_request — modify raw request payload
  4. boldform_entry_data — mutate validated entry data
  5. boldform_should_save_entry — control whether entry is persisted
  6. boldform_before_entry_save — last chance before DB insert
  7. boldform_entry_saved — after entry inserted
  8. boldform_entry_created — entry ID available, triggers integrations
  9. boldform_submission_result — filter the final JSON response

boldform_gate_submission

Return a WP_Error to block submission entirely.

add_filter( 'boldform_gate_submission', function( $result, $form_id, $form_record ) {
    if ( is_user_logged_in() === false ) {
        return new WP_Error( 'login_required', 'Please log in to submit this form.' );
    }
    return $result;
}, 10, 3 );

boldform_entry_data

Modify entry data after validation, before saving.

add_filter( 'boldform_entry_data', function( $data, $form_id ) {
    $data['submitted_url'] = sanitize_url( wp_get_referer() );
    return $data;
}, 10, 2 );

boldform_should_save_entry

Return false to skip saving the entry to the database.

add_filter( 'boldform_should_save_entry', function( $should_save, $form_id, $entry_data, $form_record, $settings ) {
    // Don't save entries for a specific form
    if ( 42 === $form_id ) {
        return false;
    }
    return $should_save;
}, 10, 5 );

boldform_entry_created

Fires after a new entry is saved. Use this to trigger external actions.

add_action( 'boldform_entry_created', function( $entry_id, $form_id, $entry_data ) {
    // Send data to an external API
    wp_remote_post( 'https://api.example.com/webhook', array(
        'body' => wp_json_encode( $entry_data ),
    ) );
}, 10, 3 );

boldform_submission_result

Filter the JSON response sent back to the browser.

add_filter( 'boldform_submission_result', function( $result, $form_id, $entry_id, $entry_data, $form_record, $settings ) {
    $result['custom_data'] = 'Extra info for JS';
    return $result;
}, 10, 6 );

Integration Hooks

boldform_integration_type_defs

Register new integration types with their configuration fields.

add_filter( 'boldform_integration_type_defs', function( $defs ) {
    $defs['my_crm'] = array(
        'type'       => 'my_crm',
        'label'      => 'My CRM',
        'icon'       => 'dashicons-admin-users',
        'color'      => '#ff6600',
        'icon_color' => '#fff',
        'category'   => 'crm',
        'desc'       => 'Sync contacts with My CRM.',
        'list_label' => 'List',
        'fields'     => array(
            array( 'key' => 'api_key', 'label' => 'API Key', 'type' => 'password', 'required' => true ),
            array( 'key' => 'list_id', 'label' => 'List',    'type' => 'list_select' ),
        ),
    );
    return $defs;
} );

boldform_integration_dispatch_{type}

Handle the actual integration dispatch when a form is submitted.

add_action( 'boldform_integration_dispatch_my_crm', function( $connection, $entry_data, $form_id, $field_map ) {
    $api_key = $connection['api_key'] ?? '';
    $email   = $entry_data[ $field_map['email'] ] ?? '';

    wp_remote_post( 'https://api.mycrm.com/contacts', array(
        'headers' => array( 'Authorization' => 'Bearer ' . $api_key ),
        'body'    => wp_json_encode( array( 'email' => $email ) ),
    ) );
}, 10, 4 );

boldform_connection_normalize_fields

Sanitize custom connection fields before storage.

boldform_connection_fetch_lists_{type}

Fetch available lists/resources for a connection type (used in settings modal).

Adding a Field Type (Step by Step)

  1. Register in field library via boldform_field_library
  2. Whitelist for save via boldform_allowed_field_types
  3. Render on frontend via boldform_field_control_html
  4. Save extra properties via boldform_field_extra_keys (optional)
  5. Add builder JS data via boldform_builder_localize_data (optional)
  6. Add builder preview via inline script (optional)

Minimal Example

<?php
// 1. Add to field library
add_filter( 'boldform_field_library', function( $lib ) {
    $lib['color_picker'] = array(
        'label' => 'Color Picker',
        'icon'  => 'dashicons-art',
        'group' => 'advanced',
    );
    return $lib;
} );

// 2. Allow saving
add_filter( 'boldform_allowed_field_types', function( $types ) {
    $types[] = 'color_picker';
    return $types;
} );

// 3. Render on frontend
add_filter( 'boldform_field_control_html', function( $html, $type, $name, $field ) {
    if ( 'color_picker' !== $type ) return $html;

    $default = esc_attr( $field['default_value'] ?? '#000000' );
    $req     = ! empty( $field['required'] ) ? ' required' : '';

    return '<input type="color" id="' . esc_attr( $name ) . '" name="' . esc_attr( $name ) . '" value="' . $default . '"' . $req . '>';
}, 10, 4 );

Adding an Integration

  1. Register the type definition via boldform_integration_type_defs
  2. Handle dispatch via boldform_integration_dispatch_{type}
  3. Optionally provide list fetching via boldform_connection_fetch_lists_{type}
  4. Optionally normalize extra fields via boldform_connection_normalize_fields

Adding a Template

Inject templates via the builder localize data:

add_filter( 'boldform_builder_localize_data', function( $data ) {
    $data['proTemplates']['my_template'] = array(
        'title'       => 'My Custom Template',
        'description' => 'A specialized form for...',
        'rows'        => array(
            array( 'columns' => array(
                array( 'width' => '100%', 'fields' => array(
                    array( 'type' => 'text',  'label' => 'Full Name', 'required' => true ),
                    array( 'type' => 'email', 'label' => 'Email',     'required' => true ),
                ) ),
            ) ),
        ),
    );
    return $data;
} );

Custom Validation

Use boldform_gate_submission for form-level validation, or boldform_entry_data for field-level checks:

add_filter( 'boldform_gate_submission', function( $result, $form_id ) {
    if ( 5 === $form_id ) {
        $age = absint( $_POST['boldform_field_age'] ?? 0 );
        if ( $age < 18 ) {
            return new WP_Error( 'age_check', 'You must be 18 or older.' );
        }
    }
    return $result;
}, 10, 2 );
