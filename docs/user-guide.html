Bold Form Lite — User Guide

A complete guide to building, styling, and managing forms with Bold Form Lite for WordPress.

Bold Form Lite is a lightweight, drag-and-drop form builder for WordPress. Build contact forms, feedback forms, registration forms, surveys, and more — with no coding required.

Key Features

  • Visual drag-and-drop form builder with live preview
  • 20+ field types including text, email, file upload, star rating, address, and more
  • Responsive row & column layouts
  • Conditional logic (show/hide fields based on user input)
  • Pre-built form templates
  • AJAX form submission (no page reload)
  • Entry management with read/unread/starred statuses
  • Gutenberg block & Elementor widget with full styling controls
  • Mailchimp & Brevo integrations
  • Google reCAPTCHA & hCaptcha support
  • SMTP email configuration
  • Export & import forms and entries
  • Full multisite support

Installation

From WordPress Dashboard

  1. Go to Plugins → Add New
  2. Search for "Bold Form"
  3. Click Install Now, then Activate

Manual Upload

  1. Download the boldform-lite.zip file
  2. Go to Plugins → Add New → Upload Plugin
  3. Choose the zip file and click Install Now
  4. Click Activate

After activation, a new Bold Form menu appears in the WordPress admin sidebar.

Your First Form

  1. Go to Bold Form → Add New
  2. Choose a template (e.g. Contact Form) or start with a blank form
  3. Add fields from the Field Library on the left by clicking them
  4. Configure each field by clicking it on the canvas
  5. Set your submission preferences in the Settings tab
  6. Click Save
  7. Copy the shortcode shown at the top (e.g. [boldform id="1"]) and paste it into any page or post
Tip: You can also embed forms using the Gutenberg block or Elementor widget — no shortcode needed.

Builder Overview

The form builder has three main tabs at the top:

TabPurpose
BuilderAdd and arrange fields on the form canvas
StyleCustomize colors, sizes, borders, and design themes
SettingsConfigure submission behavior, emails, and duplicate prevention

Sidebar

The left sidebar switches between two panels:

  • Field Library — browse and click to add fields to the selected column
  • Field Settings — configure the currently selected field (label, placeholder, required, etc.)

Canvas

The center area is the form canvas. Each form is built from rows, each row has one or more columns, and each column holds fields.

  • Click a field to select and edit it
  • Use the move handle to drag fields between columns
  • Use the duplicate and delete buttons on each field
  • Use the row action bar to move, duplicate, or delete entire rows

Row Actions

  • Settings (gear icon) — open row-level settings
  • Move (move icon) — drag to reorder rows
  • Duplicate (copy icon) — clone the entire row with all fields
  • Delete (trash icon) — remove the row

Conditional Logic

Show or hide any field based on the value of another field.

  1. Select a field and open its settings
  2. Scroll to the Conditional Logic section
  3. Toggle it On
  4. Choose an action: Show or Hide this field
  5. Set conditions: select a source field, an operator (is, is not, contains, etc.), and a value
  6. Add multiple conditions and choose AND or OR logic

Submission Settings

In the Settings tab of the builder:

Submission Type

  • AJAX (default) — submits without page reload, shows success message inline
  • Redirect — redirects to a page or custom URL after submission

Thank You Message

The message shown after a successful AJAX submission. Default: "Thanks! Your form was submitted successfully."

Redirect Options

When redirect is selected:

  • Page — redirect to a WordPress page
  • Custom URL — redirect to any URL (including external sites)

Email Notifications

Admin Email

  • Toggle admin email notifications on/off
  • Choose Site Admin (uses WordPress admin email) or Custom Email
  • Enter a custom email address when using custom mode

User Confirmation Email

  • Toggle user email notifications on/off
  • Sends a confirmation to the email address submitted in the form
  • Requires the form to have an Email field
Note: For reliable email delivery, configure SMTP in Bold Form → Settings → SMTP. Without SMTP, emails are sent using WordPress's default wp_mail() function which may not be reliable on all hosts.

Duplicate Prevention

Prevent users from submitting the same form multiple times.

  1. In the Settings tab, enable Duplicate Prevention
  2. Choose a detection method:
    • By Email — blocks duplicate submissions from the same email address
    • By IP — blocks duplicate submissions from the same IP address
    • By Field — choose any field to check for duplicates
  3. Optionally set a custom error message

Button Customization

Customize the submit button from the Settings tab:

  • Button Text — change the label (default: "Submit")
  • Alignment — left, center, or right
  • Icon — add a Dashicon or custom SVG icon
  • Icon Position — left or right of text
  • Icon Size & Gap — fine-tune spacing

Style Tab

The Style tab provides visual customization organized into sections:

Field Styling

  • Field size (small, medium, large)
  • Border style, width, radius
  • Background, text, and border colors
  • Focus color

Label Styling

  • Label size (small, medium, large)
  • Label color and sub-text color

Button Styling

  • Button size, border style, radius
  • Background, text, and border colors

Error Color

Customize the color used for validation error messages and the required indicator.

Design Themes

Apply a pre-built color theme with one click. Themes set coordinated colors for fields, labels, buttons, focus states, and error messages. You can further customize any setting after applying a theme.

Shortcode

Display a form anywhere using the shortcode:

[boldform id="YOUR_FORM_ID"]

The form ID is shown in the builder after saving. You can also copy it from the forms list page.

Gutenberg Block

  1. Edit a page/post in the block editor
  2. Click + to add a block, search for "Bold Form"
  3. Select a form from the dropdown

Block Style Controls

In the block inspector panel (right sidebar), you can customize:

  • Form — max width, padding, background, border, radius
  • Labels — text color, font size, required indicator color
  • Input Fields — height, padding, colors, border, focus color, focus background
  • Submit Button — full width toggle, padding, font size, colors, hover background, radius
  • Spacing — row gap, column gap, field gap
  • Error Messages — error color
  • Display — hide labels, hide placeholders

Elementor Widget

  1. Edit a page with Elementor
  2. Search for "Bold Form" in the widget panel
  3. Drag it to your page and select a form

Style Sections

The Elementor widget provides extensive styling controls:

  • Form Container — max width, padding, background (with gradient support), border, radius, box shadow (normal & hover)
  • Layout & Spacing — row gap, column gap, field margin, input margin
  • Labels — color, typography, margin, required indicator color
  • Input Fields — height, padding, background (gradient), colors, border, radius, focus states (border color, background color), box shadow (normal & focus)
  • Placeholder — color, typography
  • Checkbox & Radio — accent color, size, label color, typography
  • Custom Select — trigger styling, dropdown panel, search box, options (normal/hover/active states)
  • Submit Button — width, padding, typography, background (gradient), colors (normal & hover tabs), border, radius, icon color, box shadow (normal & hover)
  • Error & Success Messages — colors, background (gradient), typography

Export & Import

Go to Bold Form → Settings → Tools.

Export

  • All forms + settings — downloads everything as a JSON file
  • Single form — export a specific form
  • Settings only — export global plugin settings
  • Include entries — optionally include submission data

Import

  • Upload a previously exported .json file
  • Forms are imported with new IDs (original IDs are not overwritten)
  • Settings are merged with existing settings

Global Settings

Go to Bold Form → Settings.

General Tab

  • Form Style Mode — "Plugin" (Bold Form styles) or "Theme" (inherit from your WordPress theme)
  • Default Notification Email — fallback email for admin notifications
  • Validation Messages — customize error messages for each field type

Captcha Setup

Go to Bold Form → Settings → Captcha.

  1. Choose a provider: Google reCAPTCHA v2 or hCaptcha
  2. Enter your Site Key and Secret Key
  3. Save settings
  4. Add a Captcha field to your form in the builder
Tip: Get reCAPTCHA keys at google.com/recaptcha and hCaptcha keys at dashboard.hcaptcha.com.

Test Email

Enter a recipient address and click Send Test Email to verify your SMTP configuration.

Important: If your From Email domain doesn't match your site domain, DMARC policies may cause emails to be rejected. In this case, Bold Form automatically sets the custom email as a Reply-To address instead.

Integrations

Go to Bold Form → Integrations to connect your forms with email marketing services.

Mailchimp

  1. Click the Mailchimp card and toggle it On
  2. Click the Settings (gear) icon
  3. Enter your API Key (found in Mailchimp → Account → API Keys)
  4. Click Test Connection to load your audiences
  5. Select an Audience
  6. Optionally add Tags and enable Double Opt-in
  7. Click Save

Brevo (Sendinblue)

  1. Click the Brevo card and toggle it On
  2. Click Settings, enter your API Key
  3. Test the connection and select a Contact List
  4. Click Save

Per-Form Connection

After setting up a global connection, assign it to individual forms in the builder's Settings tab under Integrations. Map form fields (email, first name, last name) to the integration.

Multisite Support

Bold Form Lite fully supports WordPress multisite:

  • Network activation creates database tables for all existing subsites
  • New subsites automatically get tables when created
  • Each subsite has its own independent forms, entries, and settings
  • A safety net on plugins_loaded ensures tables exist even if activation was missed

Frequently Asked Questions

How do I display a form on my page?

Use the shortcode [boldform id="X"], the Gutenberg block, or the Elementor widget.

Why aren't emails being delivered?

Configure SMTP in Bold Form → Settings → SMTP. Many hosting providers block default PHP mail. Use an SMTP service like Gmail, SendGrid, or your host's SMTP server.

Can I have multiple forms on one page?

Yes. Each form operates independently with its own submission handling.

How do I add a file upload field?

Add the File Upload field from the Advanced section in the Field Library. Configure allowed file types and max file size in the field settings.

Where are uploaded files stored?

Uploaded files are stored in your WordPress uploads directory under wp-content/uploads/boldform/.

Can I style forms differently per page?

Yes. Use the Gutenberg block or Elementor widget — each instance has its own style overrides that only affect that specific form placement.

How do I prevent spam?

Bold Form includes a built-in honeypot field. For stronger protection, add a Captcha field (reCAPTCHA or hCaptcha) after configuring your keys in Settings.

Does it work with caching plugins?

Yes. AJAX submission works with page caching. If you use fragment caching, ensure the form shortcode is excluded from cache.
