BoldForm Lite — User Guide

A complete guide to building, styling, and managing forms with BoldForm Lite for WordPress.

Applies to v1.1.0 · Updated 2026-06-18

BoldForm Lite is a lightweight, drag-and-drop form builder for WordPress. Build contact forms, feedback forms, registration forms, surveys, and more — with no coding required.

Key Features

  • Visual drag-and-drop form builder with live preview
  • 25+ field types including text, email, file upload, star rating, address, and more
  • Responsive row & column layouts
  • Conditional logic (show/hide fields based on user input)
  • Pre-built form templates
  • AJAX form submission (no page reload)
  • Entry management with read/unread/starred statuses
  • Gutenberg block & Elementor widget with full styling controls
  • Mailchimp & Brevo integrations
  • Built-in Simple Math captcha, plus Google reCAPTCHA & hCaptcha support
  • SMTP email configuration
  • Export & import forms and entries
  • Full multisite support

Installation

From WordPress Dashboard

  1. Go to Plugins → Add New
  2. Search for "BoldForm"
  3. Click Install Now, then Activate

Manual Upload

  1. Download the boldform-lite.zip file
  2. Go to Plugins → Add New → Upload Plugin
  3. Choose the zip file and click Install Now
  4. Click Activate

After activation, a new BoldForm menu appears in the WordPress admin sidebar.

Your First Form

  1. Go to BoldForm → Add New
  2. Choose a template (e.g. Contact Form) or start with a blank form
  3. Add fields from the Field Library on the left by clicking them
  4. Configure each field by clicking it on the canvas
  5. Set your submission preferences in the Settings tab
  6. Click Save
  7. Copy the shortcode shown at the top (e.g. [boldform id="1"]) and paste it into any page or post
Tip: You can also embed forms using the Gutenberg block or Elementor widget — no shortcode needed.

Canvas

  • Use the row action bar to move, duplicate, or delete entire rows

Conditional Logic

Show or hide any field based on the value of another field.

  1. Select a field and open its settings
  2. Scroll to the Conditional Logic section
  3. Toggle it On
  4. Choose an action: Show or Hide this field
  5. Set conditions: select a source field, an operator (is, is not, contains, etc.), and a value
  6. Add multiple conditions and choose whether All (AND) or Any (OR) of them must match

Available Operators

isExact match
is notDoes not match
containsValue contains the text
not containsValue does not contain the text

emptyField is blank
starts withValue starts with the text
ends withValue ends with the text
greater thanNumeric comparison
less thanNumeric comparison

Confirmation

Choose what happens after a visitor submits the form (three options):

  • AJAX submit (default) — submits without a page reload and shows a success message inline
  • To a Page — redirect the visitor to a WordPress page after submission
  • Custom URL — redirect to any URL, including external sites

Thank you message

Shown after a successful AJAX submit. Default: "Thanks! Your form was submitted successfully." (With To a Page or Custom URL, the visitor is redirected instead, so the thank-you message does not apply.)

Email Notifications

Admin Email

  • Toggle admin email notifications on/off
  • Choose Site Admin (uses WordPress admin email) or Custom Email
  • Enter a custom email address when using custom mode

User Confirmation Email

  • Toggle user email notifications on/off
  • Sends a confirmation to the email address submitted in the form
  • Requires the form to have an Email field
Note: For reliable email delivery, configure SMTP in BoldForm → Settings → SMTP. Without SMTP, emails are sent using WordPress's default wp_mail() function which may not be reliable on all hosts.

Duplicate Prevention

Prevent users from submitting the same form multiple times.

  1. In the Settings tab, enable Duplicate Prevention
  2. Choose a detection method:
    • Email — blocks duplicate submissions from the same email address
    • IP Address — blocks duplicate submissions from the same IP address
    • Custom Field — choose any field to check for duplicates
  3. Optionally set a custom error message

A submission is blocked if a matching value already exists for that form in any previous (non-spam) entry. There is no time limit on the check.

Button Customization

The submit button is configured from the Submit Button field's settings — select the submit button on the canvas (in the Builder tab) to open its settings panel:

  • Button Text — change the label (default: "Submit")
  • Alignment — left, center, or right
  • Icon — none, a Dashicon, or a custom SVG icon
  • Icon Position — left or right of text
  • Icon Size, Gap & Color — fine-tune the icon

The button's visual styling (background, border, size, hover state) is set separately in the Style tab under the Submit Button section.

Style Tab (Expanded in v1.1.0)

Switch to the Style tab in the builder to open the Form Styling panel. Everything that controls how your form looks lives here in one place — a single column of collapsible sections. Design Theme is the first of these sections, followed by per-area sections (Form Container, Labels, Input Fields, and so on). Changes preview instantly on the right.

Live Preview

All style changes update instantly in the form preview area. See exactly how your form looks before saving. A device switcher (desktop / tablet / mobile) lets you preview each breakpoint.

Design Theme

The first section in the Form Styling panel. Apply a pre-built color theme with one click — themes set coordinated colors for fields, labels, buttons, focus states, and error messages. After applying a theme you can still fine-tune any individual setting in the sections below; the theme is just a starting point.

State-Based Styling

Control the appearance of fields in different user interaction states:

  • Normal — default field appearance
  • Hover — appearance when the user hovers over a field
  • Focus — appearance when the field is active/being edited
  • Checked — appearance of selected checkboxes and radio buttons

Colors, Gradients & Shadows

Within the color-based controls (form/input/button backgrounds, etc.) you can use a solid color or a gradient, and add box shadows — many of these support separate values per interaction state (for example, a different button background on hover, or a different input shadow on focus). Each section also has a reset control to return it to the defaults.

Responsive Design (Desktop/Tablet/Mobile)

Set different style values for each breakpoint:

  • Desktop — large screens (1024px+)
  • Tablet — medium screens (768px–1023px)
  • Mobile — small screens (<768px)

For example, you can use a larger font on desktop and a smaller font on mobile, or increase padding on desktop while reducing it on mobile for space efficiency.

Spam Protection

BoldForm Lite includes multiple built-in spam protection mechanisms to keep your submission queue clean:

Honeypot Field

A hidden field that catches bots. Bots auto-fill all fields, including invisible ones. If the honeypot is filled, the submission is rejected with a "Spam detected." message and no entry is saved. Enabled by default on all forms.

Captcha (Simple Math, reCAPTCHA & hCaptcha)

Add a human verification challenge:

  1. Go to BoldForm → Settings → Captcha
  2. Choose a provider: Simple Math (default, no keys needed), Google reCAPTCHA v2, or hCaptcha
  3. For reCAPTCHA or hCaptcha, enter your Site Key and Secret Key (Simple Math needs none)
  4. Add a Captcha field to your form in the builder

When the form is submitted, the captcha response is verified server-side before the entry is accepted. See Captcha Setup for full details.

Marking Entries as Spam

The Spam status is applied manually — honeypot- and captcha-blocked submissions are rejected before an entry is saved, so they never appear in the Spam tab. To flag a saved entry you believe is spam:

  • Go to BoldForm → Entries
  • Click an entry to view details
  • Use the Mark as Spam action
  • View all spam entries using the Spam filter tab

Best Practices

  • Use both honeypot + captcha for maximum protection (honeypot catches automated bots, captcha catches sophisticated attacks)
  • Monitor the spam tab to understand attack patterns and adjust field validation if needed
  • Require email field — most bots skip forms with required email validation
  • Use conditional logic to hide optional fields, reducing bot targets

File Upload Security

File uploads are restricted for security:

  • Blocked file types: SVG and SVGZ files are rejected to prevent script injection attacks
  • MIME type validation: Files are verified by content, not just extension
  • Configurable allowlist: In the File Upload field settings, you can choose which file types are allowed (PDF, images, documents, etc.)
  • Safe by default: Only explicitly allowed types are accepted; any suspicious files are rejected

Privacy & GDPR Compliance

BoldForm Lite respects user privacy and complies with GDPR and similar data protection regulations.

What Data is Collected

When a user submits a form, BoldForm stores:

  • Form Field Data — the values the user entered (name, email, message, etc.)
  • User IP Address — for duplicate detection and security logging
  • User Agent — browser/device information
  • Submission Timestamp — when the form was submitted
  • WordPress User ID — if the submitter was logged in (optional)

Data Access & Export

Users can request their data via WordPress's built-in privacy tools:

  1. Go to WordPress Admin → Tools → Export Personal Data
  2. Enter the user's email address
  3. Select "BoldForm Lite" from the list
  4. The system exports all form entries submitted from that email address as a downloadable file

Data Deletion (Right to be Forgotten)

Users can request deletion of their data:

  1. Go to WordPress Admin → Tools → Erase Personal Data
  2. Enter the user's email address
  3. Select "BoldForm Lite"
  4. Confirm the request
  5. All form entries submitted from that email are permanently deleted

Data Retention Policy

BoldForm does not automatically delete entries. You are responsible for:

  • Setting a retention policy — decide how long to keep submissions (e.g., 1 year for compliance)
  • Regular cleanup — periodically delete old entries from BoldForm → Entries
  • Documenting your policy — mention data retention in your privacy policy and terms of service

Email Privacy

  • Submission emails are sent directly from your server (via SMTP) to your configured address
  • User confirmation emails can be sent if you enable user notifications in form settings
  • No third-party email tracking — emails are not routed through external services

Integration Privacy

If you use integrations (Mailchimp, Brevo):

  • Shared fields only — only fields mapped in the integration are sent to the service (e.g., email, first name)
  • Service terms apply — those services' privacy policies govern data handled by them
  • You control the mapping — choose which form fields map to which integration fields

Privacy Policy Language

Include the following in your site's privacy policy:

"Forms on this site collect user submissions including name, email, and message content. This data is stored securely and retained for [your retention period]. Users can request data export or deletion via the privacy tools at [your admin URL]/wp-admin/tools.php?page=export_personal_data."

Accessibility

BoldForm Lite is built with accessibility in mind to ensure all users, including those with disabilities, can submit forms successfully:

  • Keyboard Navigation — all form fields and buttons are accessible via keyboard Tab, Shift+Tab, and Enter keys
  • Screen Reader Support — form labels, error messages, and field descriptions are announced by assistive devices
  • Validation Announcements — when a field fails validation, the error is announced to screen readers immediately
  • Star Rating Widget — keyboard and screen-reader accessible rating control with arrow key navigation
  • Custom Select Dropdown — accessible dropdown with search support, fully navigable via keyboard
  • Focus Indicators — clear visual indicators show which field has focus
  • Color Contrast — the default styles are designed to meet WCAG AA contrast (verify contrast if you customize colors in the Style tab)
  • Required Field Indicators — marked both visually (asterisk) and semantically (aria-required)

Pro Features Overview Pro

BoldForm Pro extends Lite with advanced features for complex forms, payments, and automation:

Multi-Step Forms

Break long forms into multiple steps with progress bar and navigation:

  • Page Break field — divides form into logical sections
  • Progress bar — shows user progress through steps
  • Navigation buttons — Previous/Next buttons to move between steps
  • Conditional step visibility — show/hide entire steps based on previous answers
  • Per-step validation — validate each step before advancing

Payments & Order Management

Collect payments and manage orders directly in forms:

  • Product field — let users select products with prices
  • Quantity field — adjust order quantities
  • Custom Amount field — user-entered prices (donations, custom fees)
  • Order Summary field — displays itemized order with live total
  • Payment gateways — collect payments via PayPal and Stripe

Auto-Populate Fields

Pre-fill form fields from multiple sources:

  • URL parameters — extract values from query strings (e.g., ?name=John)
  • User data — auto-fill logged-in user's name, email, etc.
  • User metadata — pull from custom WordPress user fields
  • Custom sources — hook into any external data source (database, API)

Form Scheduling & Limits

Control when forms are open and limit submissions:

  • Schedule open/close dates — automatically enable/disable forms on specific dates
  • Time-based scheduling — open form only during certain hours
  • Submission limits — limit total submissions (e.g., max 100 registrations)
  • Per-user limits — allow only 1 submission per user (per day/week/month)
  • Custom messages — show "form closed" message when unavailable

Webhooks & Pro Integrations

Send form data to external systems:

  • Webhooks — POST submission data to external URLs in real time
  • Many more integrations — beyond Lite's Mailchimp & Brevo, Pro adds services such as ActiveCampaign, ConvertKit, HubSpot, Google Sheets, Slack, Zapier, and Make.com
  • Custom destinations — hook into your own backend via webhooks or the integration APIs

Form Analytics

Track form performance and user behavior:

  • View count — how many people opened the form
  • Conversion rate — what percentage submitted
  • Submission trend — daily/weekly submission volume
  • Field abandonment — which fields cause users to drop off
  • Performance reports — exportable analytics for stakeholders

Shortcode

Gutenberg Block

Block Settings

The BoldForm block keeps styling in the form itself — the block simply renders the form using the design you set on its Style tab. The block inspector (right sidebar) has a small Form Settings panel with just these controls:

  • Select Form — choose which form to display
  • Edit this form in builder — a shortcut link to open the selected form in the builder
  • Hide Labels — render the form without field labels
  • Hide Placeholders — render the form without placeholder text

To change colors, spacing, borders, or button styling for a block-embedded form, edit the form's Style tab in the builder. For per-placement visual overrides directly in the page editor, use the Elementor widget instead, which exposes the full set of style controls.

Elementor Widget

  1. Edit a page with Elementor
  2. Search for "BoldForm" in the widget panel
  3. Drag it to your page and select a form

Style Sections

  • Form Container — max width, padding, background (with gradient support), border, radius, box shadow (normal & hover)
  • Layout & Spacing — row gap, column gap, field margin, input margin

  • Input Fields — height, padding, background (gradient), colors, border, radius, focus states (border color, background color), box shadow (normal & focus)
  • Placeholder — color, typography
  • Checkbox & Radio — accent color, size, label color, typography
  • Custom Select — trigger styling, dropdown panel, search box, options (normal/hover/active states)
  • Submit Button — width, padding, typography, background (gradient), colors (normal & hover tabs), border, radius, icon color, box shadow (normal & hover)
  • Error & Success Messages — colors, background (gradient), typography

Filtering & Actions

Export & Import

  • All forms + settings — downloads everything as a JSON file
  • Single form — export a specific form

Global Settings

Go to BoldForm → Settings. The Settings page has four tabs: General, Captcha, SMTP, and Tools. (Integrations is a separate top-level menu item, not a Settings tab — see Integrations.)

General Tab

  • Form Style Mode — "Plugin" (BoldForm styles) or "Theme" (inherit from your WordPress theme)
  • Default email — fallback recipient for admin notifications (leave blank to use the site admin email)
  • Validation Messages — customize the default error message for each field type
  • Data — an opt-in toggle to delete all forms, entries, and settings when the plugin is uninstalled (off by default, so your data is preserved on uninstall)

Captcha Setup

Go to BoldForm → Settings → Captcha and choose one of three providers:

  • Simple Math (default) — a built-in arithmetic challenge (e.g. “3 + 4 = ?”). Works out of the box with no API keys and no third-party requests.
  • Google reCAPTCHA v2 — the “I'm not a robot” checkbox. Requires a Site Key and Secret Key.
  • hCaptcha — a privacy-focused reCAPTCHA alternative. Requires a Site Key and Secret Key.

To set up a key-based provider:

  1. Choose Google reCAPTCHA v2 or hCaptcha
  2. Enter your Site Key and Secret Key
  3. Save settings
  4. Add a Captcha field to your form in the builder

For Simple Math there are no keys to enter — just add a Captcha field to your form. In every case the response is verified server-side before the entry is accepted.

Tip: Get reCAPTCHA keys at google.com/recaptcha and hCaptcha keys at dashboard.hcaptcha.com.

SMTP Configuration

Go to BoldForm → Settings → SMTP.

The SMTP tab has two sub-tabs: Configuration (settings below) and Mail Test (send a test message).

Configuration

The Sender details (From Name, From Email, Reply-To) apply to all BoldForm emails, even when SMTP is turned off. The remaining settings apply only when SMTP is enabled.

SettingDescription
From NameSender display name (applies even without SMTP)
From EmailSender email address (applies even without SMTP)

Enable SMTPYes/No — route mail through your SMTP server
SMTP HostMail server hostname (e.g. smtp.gmail.com)
SMTP PortServer port (usually 587 for TLS, 465 for SSL)
EncryptionNone, TLS, or SSL
AuthenticationEnable if the server requires login
UsernameSMTP account username (shown when authentication is on)
PasswordSMTP account password (shown when authentication is on)

Mail Test

On the Mail Test sub-tab, fill in the To / Subject / Message fields and click Send Test Mail to verify your configuration.

Important: If your From Email domain doesn't match your site domain, DMARC policies may cause emails to be rejected. In this case, BoldForm automatically sets the custom email as a Reply-To address instead.

Integrations

Go to BoldForm → Integrations to connect your forms with email marketing services. The page groups providers into category tabs (Newsletter, CRM, Productivity, Automation, Messaging, Storage). In BoldForm Lite, Mailchimp and Brevo are fully functional; the other provider cards are previews labelled "Available in BoldForm Pro."

Mailchimp

  1. Click the Mailchimp card and toggle it On
  2. Click the Settings (gear) icon
  3. Enter your API Key (found in Mailchimp → Account → API Keys)
  4. Click Test Connection to load your audiences
  5. Select an Audience
  6. Optionally add Tags and enable Double Opt-in
  7. Click Save

Brevo (Sendinblue)

  1. Click the Brevo card and toggle it On
  2. Click Settings, enter your API Key
  3. Test the connection and select a Contact List
  4. Click Save

Per-Form Connection

After setting up a global connection, assign it to individual forms in the builder's Settings tab under Integrations. Map form fields (email, first name, last name) to the integration.

Troubleshooting

Form Not Showing on Page

Problem: The form shortcode or block doesn't render.

Solutions:

  • Verify the form ID is correct: [boldform id="1"] (replace "1" with your actual form ID)
  • Check that the form status is Published (not Draft) in the Forms list
  • If using a block, ensure you selected a form from the block inspector dropdown
  • Clear your page cache if using a caching plugin

Styles Look Wrong (Theme Conflicts)

Problem: Form fields are sized oddly, colors are wrong, or layout is broken.

Solution: Go to BoldForm → Settings → General and toggle Form Style Mode from "Theme" to "Plugin". This tells BoldForm to use its own CSS instead of inheriting conflicting theme styles. If that fixes it, the issue is theme-related; you can adjust individual field styles in the Style tab to blend with your theme.

Form Submissions Not Working (AJAX Disabled)

Problem: Form doesn't submit, or page reloads when you click Submit.

Solutions:

  • Check browser console (F12) for JavaScript errors
  • Disable any JavaScript minification/optimization plugins temporarily to rule them out
  • If AJAX is disabled by your hosting, the form will fall back to a classic POST submission (page reloads) — this is normal and still works
  • Verify the nonce is loading: look for boldform_nonce in the page source

Emails Not Being Delivered

Problem: Admin and user emails are not arriving.

Solutions:

  • Configure SMTP: Go to BoldForm → Settings → SMTP. Many hosting providers block PHP's default mail(); you must use SMTP.
  • Use a reputable SMTP service: Gmail, SendGrid, your host's mail server, or an email marketing service
  • Check spam folder: DMARC/SPF/DKIM issues may cause emails to be flagged as spam
  • From Email domain mismatch: If your From Email domain doesn't match your site domain, DMARC may reject it. BoldForm automatically uses it as a Reply-To instead.
  • Send a test email: Go to the SMTP tab's Mail Test sub-tab and use "Send Test Mail" to verify configuration

Entries Not Saving

Problem: Form submits successfully but no entry appears in the Entries list.

Solutions:

  • Check whether the submission was blocked as a duplicate, or rejected by the honeypot/captcha (rejected submissions are not saved and do not appear in the Spam tab)
  • Verify the form status is Published
  • Check if a validation hook is rejecting the entry (custom code via `boldform_gate_submission` filter)
  • Check server error logs for database errors

File Uploads Not Working

Problem: File upload field rejects all files or doesn't upload.

Solutions:

  • Check file type: SVG and SVGZ files are rejected for security. Allowed types are configured in the field settings.
  • Check file size: Verify the file is under the max size limit configured in the field
  • Check WordPress upload limit: Go to Settings → Media and increase "Max upload file size" if needed
  • Check server limits: Your hosting may have PHP `upload_max_filesize` and `post_max_size` limits; contact your host to increase them
  • Check permissions: Ensure wp-content/uploads/ is writable

Validation Errors Not Showing

Problem: Invalid entries submit without error messages.

Solutions:

  • Ensure validation rules are enabled in field settings (e.g., "Required", "Email", min/max)
  • Check browser console for JavaScript errors that may prevent validation
  • Verify the custom error message is not empty (leave blank to use the default)

Duplicate Prevention Not Working

Problem: Users can submit the same form multiple times from the same IP.

Solutions:

  • In the form's Settings → Security tab, verify Duplicate Prevention is enabled and a detection method (Email, IP Address, or Custom Field) is selected
  • The check has no time limit — it blocks a submission if a matching value exists in any previous non-spam entry for that form
  • If IP detection isn't reliable (e.g., behind a proxy), switch to the Email or Custom Field method, or add an email uniqueness check with the `boldform_validate_field` filter

Multisite Support

BoldForm Lite fully supports WordPress multisite:

  • Network activation creates database tables for all existing subsites
  • New subsites automatically get tables when created
  • Each subsite has its own independent forms, entries, and settings
  • A safety net on plugins_loaded ensures tables exist even if activation was missed

Frequently Asked Questions

How do I display a form on my page?

Use the shortcode [boldform id="X"], the Gutenberg block, or the Elementor widget.

Why aren't emails being delivered?

Configure SMTP in BoldForm → Settings → SMTP. Many hosting providers block default PHP mail. Use an SMTP service like Gmail, SendGrid, or your host's SMTP server.

Can I have multiple forms on one page?

Yes. Each form operates independently with its own submission handling.

How do I add a file upload field?

Add the File Upload field from the Advanced section in the Field Library. Configure allowed file types and max file size in the field settings.

Where are uploaded files stored?

Uploaded files are stored in your WordPress uploads directory under wp-content/uploads/boldform/.

Can I style forms differently per page?

Yes. Use the Gutenberg block or Elementor widget — each instance has its own style overrides that only affect that specific form placement.

How do I prevent spam?

BoldForm includes a built-in honeypot field. For stronger protection, add a Captcha field — the default Simple Math challenge works with no setup, or switch to reCAPTCHA/hCaptcha after configuring your keys in Settings.

Does it work with caching plugins?

Yes. AJAX submission works with page caching. If you use fragment caching, ensure the form shortcode is excluded from cache.

How do I export entries as CSV?

Go to BoldForm → Entries, view the entries you want to export, and click the Export CSV button. All visible entries are exported as a spreadsheet file that you can open in Excel or Google Sheets.

Can I delete old entries to comply with GDPR?

Yes. Open an entry from BoldForm → Entries and use the Delete action to remove it. To remove all entries tied to a person, use the WordPress privacy tools at Tools → Erase Personal Data, which delete every entry from a specific email address.

How do I style the file upload drop-zone?

In the Style tab, open the File Upload section. You can customize the drag-and-drop drop-zone's background color, border, and icon/text color.

Can I have different styles for different devices (mobile, tablet, desktop)?

Yes. In the Style tab, every styling control has tabs for Desktop, Tablet, and Mobile. Set different values for each breakpoint. For example, you can use a larger font size on desktop and a smaller one on mobile.

What's the difference between honeypot and captcha?

Honeypot is invisible and catches automated bots (they auto-fill all fields). Captcha is visible and requires human verification (solving a puzzle). Use both for maximum spam protection: honeypot catches bots, captcha catches sophisticated attacks.

Can I manually mark entries as spam?

Yes. Go to BoldForm → Entries, click an entry, and select Mark as Spam. You can view all spam entries in the Spam filter tab.

Can I customize validation error messages?

Yes. Go to Settings → General to set default error messages for each field type. In the form builder, you can also set custom error messages for individual fields under Field Settings.
